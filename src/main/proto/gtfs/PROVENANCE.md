# gtfs-realtime.proto

Unmodified copy of the GTFS Realtime protocol definition (Apache License 2.0, see the file header).

- Source: https://github.com/google/transit/blob/474750a163088673df718838d4a1bb093391f9af/gtfs-realtime/proto/gtfs-realtime.proto
- Spec: https://gtfs.org/documentation/realtime/reference/

Pinned to a commit so builds are reproducible. To update: download the file at a newer commit, update this link,
and run the tests (the client and mapping tests parse real GTFS-Realtime messages).
